DailyBee is a developer time tracker that runs on your own machine. It keeps a timer per task, watches which app and browser tab is in front, pulls you back when you drift, and turns the day into a report you can correct by hand and send to your team. Product

Everything a developer's day needs. Nothing it doesn't.

One-click tracking

Start from the app, the tray, a global shortcut or a git commit. Idle, lock and sleep pause the timer, and when you come back DailyBee asks what to do with the time away.

See where the time went

Apps and browser pages sorted into Work, Research, Learning, Communication and Distraction. A timeline, a focus percentage and a quiet check-in when you drift.

Correct the record

Edit, split, delete or add entries. Every change lands in an append-only, hash-chained log, and corrected entries carry a badge.

Reports that write themselves

Entries, activity and check-ins become a daily report. Send it to Slack or email, copy it as Markdown, and look back at any day or week.

Tasks and projects

Sizes from Trivial to Epic, logged time against the estimate, priorities, a board, and weekly budgets per project.

Solo or team

A local profile with a password, or a workspace on a server you run, where leads see team and admin views built from aggregates only.

How it works

A day in DailyBee

Every screenshot below is the sample day that ships with the app, captured from the real thing.

1 · Track

Start a task, then forget about it

Pick a task, say what done looks like, and get on with the work. DailyBee counts active time only and names what you are doing.

  • The timer pauses on idle, lock and sleep, and asks about the time away when you return
  • The tracker reads the app in front and the browser's address bar, without an extension
  • Check-ins on drift and at the halfway point, answered with one click
2 · Report

At 18:00, the day is already written

Generate report turns entries, activity and check-in answers into a draft. Read it, fix a line, send it.

  • Send to Slack or email, or copy as Markdown
  • Week view: tracked time, focus and report state for seven days, hours per project against the budget
  • History for every day, with the same cards as Today
3 · Correct

Correct it, honestly

Forgot to start the timer, or stopped it late? Fix the entry. The change is recorded, not hidden.

  • Edit, split, delete or add entries from the Entries card
  • Each change is appended to a hash-chained log the app can add to but never alter
  • Corrected rows show an Edited badge, and a report that was already sent offers Send again
4 · Team

Grow into a team without giving up privacy

Optional. A workspace lives on a server you run; the desktop app only ever sends aggregates to it.

  • API, Postgres and the update feed start with one Docker Compose file
  • Leads see app names, categories and totals, never page URLs or window titles
  • Solo profiles never touch the network
5 · Focus

When you drift, it asks you back

Open a distraction site in the middle of a task and DailyBee notices. It interrupts, briefly, and asks whether you meant to.

  • A small Drifting? card after a few minutes on a distraction site: Back to it, Taking a break, or This is work
  • Stay there and a full-screen warning steps in front of everything until you answer
  • Answers go into the report; This is work teaches it that the site counts as work for you

      Privacy
      
    Your URLs never leave your machine.
    
      
    Per-page addresses and window titles are the most revealing data a tracker holds. DailyBee keeps them on the device, always. What a team ever sees is a category and a duration.
    
    
    
    
    
      
    
        
    Solo profile
    
        
      
          
    • Everything in one SQLite file per profile, in your user folder
      • 
          
    • Backups are files you export and keep wherever you like
      • 
          
    • No account, no sign-in, no network calls
      • 
        
    
      
    
      
    
        
    Team workspace
    
        
      
          
    • App names, categories and durations, per day
      • 
          
    • The reports you choose to send
      • 
          
    • Page URLs and window titles, ever
      • 
        
    
      
    
      
    
        
    Always
    
        
      
          
    • Every payload is scrubbed on the client and rejected again by the server's strict schemas
      • 
          
    • A private-apps list: whatever is on it is never recorded
      • 
          
    • No keystrokes, no screenshots, no camera
      •

    Build it yourself
    
        
    # Node.js 22 or newer, git
git clone <repository> daily-bee
cd daily-bee
corepack enable        # once; makes the pinned pnpm available
pnpm install
pnpm dev               # run it with real tracking
pnpm package           # build the installer for this platform
    
        
      
          
    • One command builds the installer for the platform you are on: NSIS on Windows, dmg on macOS, AppImage and deb on Linux
      • 
          
    • No native modules to compile: the trackers are scripts and system interfaces
      • 
          
    • A GitHub Actions workflow builds and signs releases for all three platforms and serves self-updates from a feed you host
      • 
          
    • pnpm dev:demo starts the app with the sample day, the quickest way to see every screen
      •
